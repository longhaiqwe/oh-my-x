# oh-my-x 2.8.0 产品功能说明动图

用途：给 X 发布前准备的两张独立 GIF，附 MP4 和可编辑源码。不上线、不发布、不操作真实 X 账号。
依据：本地 v2.8.0 与 v2.7.0 标签，CHANGELOG.zh-CN.md，favorite-blogger-lookup.ts、favorite-bloggers.ts、profileActions.ts、quick-list.ts。XChat 引用帖子属于 2.7.0，排除。
StageShow：复制 share gold 作为结构起点，保留 Stage、Window、Popover、Field、Row、Collapse 及测量目标的鼠标动作；使用实际面板文案与圆角、字体、按钮尺寸。主画面 840×560，手机栏另做 358×500。
1. 昵称查找：打开收藏→中文昵称输入→点击带关注状态的候选→收藏结果→英文昵称查询→明确的按用户名收藏项与键盘选候选→结果停留→关闭复位。演示账号是虚构样本。
2. 交互优化：主页紧凑操作→收藏→从导航查看收藏→Esc 关面板并还焦点→打开我的列表→再次点击入口关闭→重新打开并点外部关闭。循环只在遮挡后重置数据。
中英文昵称查找均是真实功能；图像是源代码核对后的 authored UI，不是实录。两张均保留「界面模拟 · 演示账号」标识。
