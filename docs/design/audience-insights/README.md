# 粉丝与关注分析：第二版设计原型

日期：2026-11-11。第二版已逐张查看用户文章中的11张图片后重新设计；使用 Refactoring UI，沿用 oh-my-x 既有主题。当前只交付设计，不接入扩展功能。所有账号、时间与数据均为合成演示。

## 打开

直接打开 `index.html`，或从 `docs/design` 启动本地静态服务器，访问 `/audience-insights/?panel=1`。网页依赖同目录的 `style.css`、`prototype.js` 与上层 `tokens.css`。支持参数 `view=followers|following|settings`、`theme=light|dark|dim`、`panel=1`。

顶部是原型评审工具，可选择粉丝构成、关注分析、设置归属，切换主题、灰阶和数据状态；这些工具不属于实际产品界面。窄屏打开全屏分析时先关闭窗口，再使用评审工具。

## 本次修改的原理与内容

第一版把完整分布放在440px抽屉中，账号名单位于其后。原图的宽窗口能容纳更多账号，适合“看某一档有哪些人”的任务，因此本版改为最大1040px的模态分析窗口。

- 粉丝构成：三个累计阈值为同一信息组；下面左侧分布、右侧两列紧凑账号。点击指标或分档直接更新右侧名单。三个累计条件相互包含，六个分档互不重叠，二者分开解释。
- 关注分析：关系单选与属性叠加筛选分开。人数、搜索、排序放在分析窗口内，表格展示粉丝数、关注数、粉丝/关注比和与当前登录账号的关系。
- 窄屏：≤700px全屏；粉丝构成分为“分布概览／账号名单”两个视图，切换时保留筛选；关注分析改为单列卡片。
- 操作层级：导出为次要操作，“返回列表继续加载”为主要操作。分析时背景停止交互，关闭后恢复列表与焦点。清除记录放在设置中。
- 设置归属：仍放在“数据 → 看板 → 粉丝与关注分析”，位于博主活动度之后。

正式设计与11张图片的逐项映射见 `../../plans/audience-insights-design-2026-11-11.md`。源码拆为HTML、CSS、JavaScript便于后续评审。没有新增依赖。

## 原型交互与数据

粉丝构成默认264条，六档人数采用原图的168、52、26、9、6、3；账号名字、用户名、具体粉丝数重新合成。顶部累计汇总为96、44、18，比例统一保留一位小数。选择“部分缺失”时额外加入8条缺少粉丝数的记录，共272条，比例仍以264条有效资料为分母。

关注分析使用90条合成数据：50条明确未关注当前账号，34条已关注，6条关系未获取。属性人数在当前关系筛选范围内计算，表示单独符合此属性的人数；属性组合后的结果数在名单标题旁显示。粉丝/关注比仅在粉丝数已知、关注数大于0时计算。

原型可以筛选、搜索、排序、分页和导出全部筛选结果。不会连接X或保存设置，也不提供虚构账号的外部主页链接。真实名单解析、持久化、空间管理、账号状态详情、通知提示、复盘与分享名片尚未实现。

## Refactoring UI 复核

按信息层级、布局、文字、颜色、层次、图像、空状态的顺序检查桌面、窄屏和深色截图。

| 维度 | 规则 | 结果 |
| --- | --- | --- |
| 信息层级 | §2.1、§2.8 | 三个汇总为一组，分布与账号并列；不增加质量总分；导出次要 |
| 布局 | §3.3、§3.6 | 桌面1040px上限，内边距24px、组内12px；窄屏16px及双视图 |
| 文字 | §4.1、§4.7 | 沿用12–20px刻度和400/600字重；数字右对齐，比例含明确分母 |
| 颜色 | §5.6、§5.7 | 中性图表，选中态跟随X强调色并加勾选；不照搬渐变色 |
| 层次 | §6.2 | 窗口一层阴影；账号项用浅底分组，不逐项叠边框和阴影 |
| 图像 | §7.4 | 合成账号采用固定尺寸占位；正式版头像应固定容器并object-fit:cover |
| 空状态 | §8.4 | 无名单、字段缺失、筛选无结果分别展示，不把错误表示为0个粉丝 |

沿用第一版已计算的颜色对比度：亮色次要字／白底6.12:1，亮色次要字／浅灰底5.47:1，暗色次要字／黑底7.00:1，深蓝次要字／深蓝底5.50:1，选中正文／浅蓝底16.34:1。第二版未更改这些配色。真实X动态强调色组合仍需接入时检查。
