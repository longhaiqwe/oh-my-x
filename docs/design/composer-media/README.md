# 多图排序交互

日期：2026-11-13（北京时间）。

## 问题与方案

原实现的图片上限为 4，并且拒绝处理多层轮播包装。超过四张时，布局和拖动监听均不生效。

- 2–4 张：保留原来的两列网格。
- 5–20 张：默认总览，桌面 5 列、窄屏 4 列；可切换为两列大图。
- 两种模式均可上下、左右拖动；大图限制区域高度，拖到上下边缘自动滚动。
- 网格生效时隐藏附件区原生轮播的左右箭头；退出网格或关闭功能后恢复。图片编辑、移除按钮及底部工具栏不受影响。
- 选择图片编号后，可直接移到开头或末尾。编号表示当前位置，选择状态跟随图片身份。
- 松手后通过原有页面桥接逻辑修改 X 的媒体数据。拖动预览只调整 CSS 排序，不搬动 X 管理的节点。
- Esc、窗口失焦、附件被移除时取消拖动。数据不完整、有视频或 GIF 时保留原布局。

## 设计依据

采用 refactoring-ui 技能。项目设置页使用 Vue / Tailwind 4，但此功能使用原生页面元素和注入 CSS，没有新增依赖。

- §2.1、§2.8：图片为主要内容，模式切换其次，移动快捷按钮和提示再次之。
- §3.6：控件内部间距 8px，工具栏与图片之间 12px；控件 13px、提示 12px，字重限定为 400/600；采用项目现有的 8px 圆角和主题颜色。
- §5.7、§7.2：序号使用 X 主题色实底和项目配套文字色；拖动状态同时有透明度和虚线边界。
- §7.3.2：总览用于识别位置，大图用于查看细节；保持图片完整显示。
- 键盘焦点、边缘滚动与取消逻辑属于交互补充，不作为书中原有规则。

按 hierarchy → layout → typography → color → depth → images → finishing 顺序检查。本地渲染中未发现需阻断交付的层级、溢出或图片裁切问题。工具栏复用现有深浅主题色；X 真实页面中的原生编辑按钮、轮播导航及嵌套布局仍需复核。

## 字体与工具栏修订（2026-11-13）

用户反馈功能已基本测试完成，工具栏文字与原界面不一致。真实页面检查发现原生媒体按钮使用 TwitterChirp 字体栈，附件父容器为另一字体，而排序工具栏写死了系统字体。因此复用项目的 `getXFontFamily`，从原生媒体按钮取样，不直接继承父容器字体。

| 位置 | 问题 | 规则 | 调整 |
| --- | --- | --- | --- |
| 工具栏文字 | 未复用项目字体方法 | §1.5、§4.2 | 从原生文字读取字体 |
| 模式切换 | 黑底按钮过于突出 | §2.8 | 改为浅底分段控件，选中项保留边界和字重区分 |
| 图片数量 | 14px 粗体比辅助标签更突出 | §2.2、§2.6 | 13px 常规字重，次要文字色 |
| 快捷操作 | 每项都有胶囊边框 | §8.5 | 改为文字按钮，悬停显示底色 |
| 下拉框 | 原生外观与自定义焦点叠加 | §8.1 | 统一外观，焦点处以单层轮廓替代边框 |

本次只调整工具栏样式和分组，排序逻辑不变。原设计说明中“沿用字号与圆角”的表述不够准确，已补充实际值及字体取样方式。
