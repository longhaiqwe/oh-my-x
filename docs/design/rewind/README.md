# 回看交互原型

设计日期：2026-11-10。对应方案：`../../plans/rewind-integration-design-2026-11-10.md`。

正式功能现已实现。本文以下内容记录静态原型阶段；扩展实装验证见 [验收记录](../../plans/rewind-integration-verification-2026-11-10.md)。`implementation/` 下的桌面、暗蓝、设置、OCR 和窄屏截图来自真实扩展包与虚构 X 页面，不含用户数据。

直接打开 `index.html`，或从仓库根目录运行 `python3 -m http.server 4178 --bind 127.0.0.1`，访问 `http://127.0.0.1:4178/docs/design/rewind/`。

## 可审阅内容

- X 左侧入口与右侧回看面板；白色、暗蓝、黑色和两种示例强调色。
- 插件 400 × 600 弹窗、阅读分组卡片、弹窗内第二层设置与完整设置页。
- 关键词搜索、五种类型筛选、预设图片文字搜索。开启图片文字后可搜索「可访问性」。
- 自动记录暂停、导航显隐、OCR 示例失败与重试、清空取消与确认、无结果及无记录状态。
- 窄屏全屏面板、Esc 关闭、快捷键演示、焦点约束与返回。

原型初始展示「已启用并保存六条记录」的使用场景。正式功能设计为默认关闭，见方案。所有账号和记录均为虚构示例；原帖按钮显示提示，不访问虚构链接；开关和清空只改变内存。刷新或「重置示例」恢复初始状态。

原型没有实现真实采集、IndexedDB、下载、OCR、语言切换、无限加载或真实 X 导航。「更多」入口在窄屏中仅示意位置，正式实现需验证 X 菜单挂载。完整交互约束以设计方案为准，不将原型作为业务实现直接接入。

## 已完成的原型验证

2026-11-10，使用本机 Chrome 157.0.8103.39 的无头浏览器检查：

- 390、600、1024、1440px 四种宽度 × 浅色、暗蓝、深色三种主题，共 12 种组合，均无页面横向溢出。
- 390／600px 面板与视口等宽；1024／1440px 面板宽 440px。
- 搜索无结果、视频筛选、图片文字预设命中、暂停后查阅、清空取消与确认、关闭记录后的空态、Esc 关闭均通过交互断言。
- 弹窗详细设置在弹窗内部显示；返回后恢复阅读分组视图；暂停状态在设置与回看面板间一致。
- 窄屏背景设置 inert，面板支持键盘焦点约束；检查中无脚本运行异常；首轮页面资源没有 HTTP 错误。
- 已查看桌面、设置、弹窗、窄屏截图，并去除截图中的临时状态提示。

这轮没有修改业务代码，没有运行扩展构建与全量测试；上述结果不证明真实采集、OCR、持久化或生产环境性能。后续实施验收项列在方案第 8 节。
