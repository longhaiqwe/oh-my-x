# oh-my-x 2.4.0 全功能测试指南

日期：2026-10-23。范围：主分支原有功能、AI 评论分支及其尚未提交的功能改动，以及「按名字艾特」分支。

## 安装或更新

测试包：`build/oh-my-x-2.4.0-chrome-mv3.zip`，解压得到 `chrome-mv3/`。

- 已从本项目加载扩展：打开 `chrome://extensions`，在 oh-my-x 卡片上点击重新加载。本项目的生产目录仍是 `build/chrome-mv3/`。
- 已从其他目录加载：将包内文件覆盖到原来加载的目录，再重新加载扩展。保持原目录、不要先移除扩展，以保留设置和本地数据。
- 首次安装：开启开发者模式，点击「加载已解压的扩展程序」，选择解压后的 `chrome-mv3/`。
- 确认扩展版本为 **2.4.0**，再刷新已打开的 X 页面，使页面脚本与新版后台一致。

## AI 功能优先测试

1. 打开「设置 → AI 服务」，确认旧连接配置已迁移，或填写接口地址、API Key 和默认模型，点击「授权并测试连接」。
2. 在「过滤 → 评论垃圾过滤」中开启 AI 判断。先选「只手动」，在帖子详情页顶部点击 AI 判断按钮。
3. 确认进度计数更新、完整评分逐条显示；分数达到阈值的回复折叠，展开后可查看原文。普通 JSON 接口按整批显示。
4. 检查主帖、主帖作者及自己的回复不会被送去评分；回复另一条评论时应使用对应评论作为上下文。
5. 将一条回复标为「机器人」，检查该账号其他回复也会折叠；撤销标记或改标「真人」，检查显示恢复。导出「我的标注」并确认 JSONL 可读取。
6. 测试自动判断范围、每日自动额度、调试模式，以及失败后的重试。刷新后已有评分应复用缓存，已完成结果不会因后续超时而丢失。
7. 在「创作 → AI 总结转发」检查独立模型覆盖、风格描述与参考样本；分别测试引用、回复弹窗和帖子详情页内联回复框。生成后选择文案、取消、关闭面板均应正常。
8. 在弹窗和完整设置页分别运行 AI 连接测试与评论样例集测试。真实模型调用使用你配置的服务并计费。

流式请求首段等待上限为 25 秒，后续连续无数据上限为 15 秒，总耗时上限为 90 秒。

## 按名字艾特

在「创作」中开启「按名字艾特」，在发帖、引用和回复编辑器里输入 `@` 加中文名字，检查候选账号、鼠标选择、方向键与回车选择，以及 Esc 关闭。选择后应替换为正确的 `@用户名`。纯英文查询由 X 原生候选框处理；关闭功能后不应再出现插件候选框。

## 右键存草稿

1. 在任意网页（例如新闻页）选中两段文字，右键点「存为 X 草稿」。扩展图标上应显示 ✓，3 秒后消失。
2. 打开 X 发帖框右上角的「草稿」，最新一条应是选中的文字，段落换行保留，最后空一行是这个网页的链接。
3. 不开 X 标签页时再试一次，应同样存进草稿箱。
4. 在「创作 → 右键存草稿」关掉，右键菜单里不应再有这一项；打开后恢复。界面语言切到 English 后，菜单名应为「Save to X drafts」。
5. 失败路径：退出 X 登录后再试，应在旁边打开 X 发帖页（登录后可见已填好的文字）。

## 原有功能回归

| 模块 | 建议逐项检查 |
| --- | --- |
| 界面 | 时间线与导航宽度、右侧栏、发帖按钮、导航按钮与文字、长文目录 |
| 过滤 | 规则与阈值、关键词、黑白名单、调试条、拦截记录与统计、正文关键词折叠/隐藏 |
| 数据 | 创作者奖励、博主活动度、爆款雷达、粉丝与互动比、粉丝数、收藏量 |
| 创作 | 帖子库同步与引用、多图两列与拖动排序、按名字艾特、Markdown/链接、排期全景与右侧栏排期 |
| 互动 | 快捷键、底部悬浮条开关、直达回复、回复后点赞、媒体下载、未关注者高亮、Lists |
| 设置 | 中文/英文切换、AI 服务配置、弹窗与完整设置页的一致性、重启后设置保留 |

建议至少在首页、帖子详情页、个人主页和 X Pro 对话栏各检查一次，并确认关闭功能后相应按钮、标签或隐藏状态会清理。

## 自动验证与边界

验证命令：`npm run typecheck`、`npm test -- --maxWorkers=2`、`npm run build`。

自动测试覆盖本地逻辑、模拟 DOM 和模拟接口；真实 X 页面兼容性、账号权限及实际 AI 服务效果仍需按上面的步骤测试。
