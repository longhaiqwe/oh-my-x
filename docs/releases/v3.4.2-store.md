# 3.4.2 发布与 Chrome 商店送审记录

2026-11-25 约 10:30（北京时间），Chrome 商店后台显示「已将您的扩展程序提交送审」。提交时已发布版本为 3.4.1，商品状态为「已警告」。本次关闭了审核通过后自动发布；审核通过后需要手动发布。

## Blue Argon 修复

- 原始 3.4.1 送审 ZIP（SHA-256 与发布记录一致）包含 Tesseract 7.0.0 浏览器 Worker 的远程识别引擎备用路径。OCR 页面产物也包含远程 Worker 默认路径。即使业务代码传了本地路径，原构建仍保留依赖中的两个远程可执行入口。
- 新版本移除这两个路径及 Blob Worker 启动逻辑，固定从扩展内的 `ocr/` 加载 Worker、JavaScript 引擎和 WebAssembly。语言数据仍可在首次使用时下载，不执行下载的数据。参见 [Chrome 商店远程代码规则](https://developer.chrome.com/docs/extensions/develop/migrate/remote-hosted-code)。
- 更新了中英文商品介绍及审核测试说明，保留原有隐私说明。与 3.4.1 比较，清单只改了版本号，无新增权限。

- 商店 ZIP：`oh-my-x-3.4.2-chrome.zip`，45 个文件，2,122,539 字节。SHA-256：`b703bbee42f61d56e8ae795df7b5b5abf8edb844ebe67ea6cbf3d4b0ea72706e`。
- 干净安装、类型检查、136 个文件的 1,657 项测试、生产构建和 ZIP 审计通过。旧 ZIP 的回归审计未通过。隔离 Chromium 的识别测试各运行七轮，覆盖预填和空缓存、简繁中文与英文、日文及韩文模式切换；空缓存使用语言数据测试材料模拟首次下载。
