# 3.4.0 发布与 Chrome 商店送审记录

2026-11-23 约 17:20（北京时间），Chrome 商店后台显示「已将您的扩展程序提交送审」，商品状态为「待审核」。提交前核实线上版本为 3.3.0，草稿为 3.4.0。已选中通过审核后自动发布。

同日，3.4.0 的 Chrome 商店审核已取消，由 [3.4.1](v3.4.1-store.md) 替换送审。

- 相比 3.3.0，新增 X 网页语音回复。帖子下方和回复弹窗都支持最长 30 秒的录音，可先试听或丢弃。录音在本机合成带静态画面的视频，经用户确认交给 X 的附件功能。发布仍由用户点击 X 的回复按钮。
- 本次仅合入语音功能及配套说明。和商店线上 3.3.0 的发布包逐项比较，扩展权限、主机权限、可选主机权限和内容脚本的页面范围均一致。点击录音时由浏览器请求麦克风访问。
- 更新了中英文商品说明、单一用途及主机权限理由。网站内容类别已涵盖声音和视频。保留既有数据类别及隐私政策地址。已保存 440 字符的审核测试说明，覆盖录音、试听和添加附件。
- 在独立发布目录通过依赖安装、类型检查、135 个测试文件共 1,636 项测试、生产构建与打包。在真实 X 页面以模拟音源验证录音、试听和媒体输入交接。Chrome 送审操作未在 X 发布测试回复。
- 商店包为 `oh-my-x-3.4.0-chrome.zip`，含 45 个文件，共 2,116,807 字节。根目录清单版本为 3.4.0，SHA-256（文件校验值）为 `3891175bc34caeb08a0a7919c98c236693da4f5e8cdd4d1ee939f6225d5c8950`。
