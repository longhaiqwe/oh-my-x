# 3.1.0 本地发版准备

日期：2026-11-13（北京时间）。用户已授权推送 GitHub 并提交 Chrome 商店审核。发布流程进行中，完成结果另行补记。

已在 Chrome 商店后台确认：线上版本为 3.0.0，状态为「已发布」，无待审核版本。本次更新以 3.0.0 为基线。

## 本次改动

- 多图排序扩展至 2–20 张；超过 4 张可切换总览与大图。
- 支持按编号移到首尾，大图拖动时边缘自动滚动；工具栏使用 X 字体与主题色。
- 修复编辑按钮误入图片裁剪页，以及通知卡片缩放列数和跨标签页切换问题。
- 最多 20 张指排序能力，实际上传数量由 X 决定。

中英文更新说明见 [中文更新记录](../../CHANGELOG.zh-CN.md)及[英文更新记录](../../CHANGELOG.md)的 3.1.0 条目。
