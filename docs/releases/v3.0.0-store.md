# 3.0.0 Chrome 商店送审说明

准备日期：2026-11-12（北京时间）。状态：发布准备中，未上传、未提交审核。

更新说明按 2.9.0 → 3.0.0 汇总，包含 2.10.0 的未上架改动。商店当前线上版本待重新核实，不将 GitHub 标签等同于商店上架状态。

## 操作

1. 打开[现有商品的软件包页](https://chrome.google.com/webstore/devconsole/fb54ced2-ce3b-4996-93ec-18575bd9588c/ehnedndgpdkclhddhgdkdadhbiafaend/edit/package)，确认当前版本及是否有在审版本。
2. 上传 `build/oh-my-x-3.0.0-chrome.zip`，确认识别的版本为 3.0.0。不要使用顶层带 `chrome-mv3/` 文件夹的 GitHub 手动安装包。
3. 在隐私权页更新以下权限理由和数据使用说明，并保存。
4. 商品详情追加下面的更新内容，保留现有功能介绍及截图。
5. 点击「提交审核」。沿用此前审核通过后自动发布的方式；以后台显示提交成功为准。

[Chrome 官方更新流程](https://developer.chrome.com/docs/webstore/update)要求上传完整新包、同步变更的商品及隐私资料，再提交审核；[隐私字段说明](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)要求逐项说明权限用途，并与隐私政策一致。

## 权限理由

与 2.9.0 相比没有新增权限。若线上仍为 2.8.0，需要同时补上本地图片文字识别的说明。

### offscreen

```text
Runs optional image text recognition in an extension-owned offscreen document. The Tesseract worker, JavaScript runtime, and WebAssembly are bundled with the extension. Recognition runs locally; saved post text and recognized text are not sent to the developer or an AI service.
```

### alarms

```text
Schedules own-post library synchronization in open X tabs and Creator Rewards refreshes. Also schedules recovery of pending local image-recognition work when the service worker restarts. It does not schedule or publish posts automatically.
```

### storage

```text
Stores settings, word lists, allow/block lists, block logs, AI configuration, saved bloggers and avatar URLs, cached X data, notification viewing receipts and filter choices on the device. Extension-local IndexedDB stores the own-post library, optional Rewind history and recognized image text, and optional audience lists. These records are not collected by the developer. Users can disable optional capture and clear local records.
```

### 主机权限说明补充

保留已有 X、abs.twimg.com、video.twimg.com 和自定义 AI 服务说明，并追加：

```text
Optional image-text recognition requests https://pbs.twimg.com/* for X images and https://cdn.jsdelivr.net/* for versioned language data only when enabled. Requests omit credentials. Downloaded language files are data; executable JavaScript, the worker and WebAssembly are packaged in the extension. Audience insights observes Followers, BlueVerifiedFollowers and Following responses already loaded by X without making additional list requests. Favorite avatars use X-hosted URLs; missing favorite avatars may be filled through the existing X user-search endpoint.
```

## 数据使用核对

- 个人身份信息：账号 ID、用户名、昵称、头像地址、粉丝与关注名单，主要保存在本机。
- 身份验证信息：已有 X 会话，以及用户自行填写的 AI API Key（服务密钥）。
- 网站内容：帖子正文、图片来源、本地图片识别结果及名单资料。
- 网络浏览记录和用户活动：旧资料按没有「回看」功能填写。现在可记录首页可见帖子、查看时间和通知查看状态，应据此更新申报，不再直接沿用旧表中的「不勾选」。这是对当前代码行为的申报建议；后台字段及最终选项仍待本人核对。
- 不出售数据，不用作与扩展用途无关的用途，也不用作信用评估。隐私政策地址保持为 [PRIVACY.md](https://github.com/longhaiqwe/oh-my-x/blob/main/PRIVACY.md)。
- 远程代码：本地识别运行代码随包提供，下载的语言文件是数据。未增加远程执行代码。
