# 回看：oh-my-x 集成设计

日期：2026-11-10。状态：已按用户确认以「回看」实现。下文保留实施前的设计基线，其中「尚未实测」指设计阶段；最终实现、验证结果和限制见 [实现验收记录](rewind-integration-verification-2026-11-10.md)。

配套原型：`../design/rewind/index.html`。原型使用虚构账号和示例记录，交互仅修改内存，不访问 X、不记录浏览、不执行 OCR。

## 1. 设计结论

将能力命名为「回看」，放入现有「界面与阅读 → 阅读」，保留六个模块。X 页面的主要入口放在左侧导航，使用已有导航克隆与布局同步机制；打开右侧非模态面板，不跳转首页、不改变时间线宽度。设置界面延续米白／深蓝与铜橙配色，X 页面延续宿主主题和强调色。

这项能力解决「首页刷新后找不到刚才看到的帖子」。因此主操作是查找并打开已看内容，记录设置和数据清理置于次级界面。它与「引用我的帖子」的区别是记录对象不同：前者记录本人浏览过的首页内容，后者同步本人发布的帖子。数据库和入口分别管理。

不新增独立品牌、顶层模块、右下角悬浮球、首页信息流按钮或常驻记录提示。OCR 是图片文字识别，在本机提取图片中的文字供搜索，不接入公共 AI 服务，也不要求 API Key。

## 3. 信息架构与入口

### 设置归属

保留「布局 → 导航栏 → 阅读 → 搜索」顺序。「阅读」中保留长文目录行，下方新增独立 `RewindCard`，因为它包含状态和详细设置，不能只作为一个简单开关行。

- 卡片标题：回看。
- 说明：记录在首页看到的推文，之后可按关键词查找。
- 位置说明：在哪用：X 左侧导航栏；窄屏下在「更多」菜单。
- 主开关：自动记录。首次安装和升级都默认关闭，用户开启后才记录。
- 状态：`已保存 {count} 条 · 仅本机`；关闭时为 `记录已暂停 · 已保存 {count} 条`。
- 底部操作：`打开回看`、`详细设置 ›`。两个都使用文字／描边样式。
- 即使自动记录关闭，也保留状态与两个操作。不要将其绑定到会隐藏 footer 的 `FeatureCard.enabled=false`；记录开关控制记录，功能卡片本身仍可操作。

详细设置复用 `SubPage`：标题「界面与阅读 / 回看」，返回时恢复滚动位置与焦点。包括自动记录、在导航栏显示、识别图片文字、容量说明及清空本账号记录。全部自动保存，无额外「保存」按钮。

### X 导航

- 新入口「回看」，24px 线性历史图标，字号、字重、行高、悬停背景取原生导航参考项。
- 放在 Home 后方；保持现有「收藏 → 我的列表 → Home」相邻关系，不在这些入口之间插入，避免独立扫描器反复调整顺序。
- 图标模式只显示图标，保留可访问名称和提示；打开面板使用 `aria-expanded`，不将非页面入口标记成当前路由。
- 默认在用户第一次启用记录后显示；后续暂停记录不移除入口。导航显隐为独立设置。
- X 各页面可打开已有记录，仅首页采集。离开首页后停止采集，面板可继续查找。
- 窄屏无左导航时，在原生「更多」菜单可见时注入入口；不挤占底部固定导航。需在实现阶段验证菜单挂载点。
- `Alt+Shift+R` 使用独立 command `open-rewind`，不能沿用 `_execute_action`，否则会打开 oh-my-x 的设置弹窗。快捷键可在浏览器扩展快捷键页修改。
- 从 popup 点击时向当前可用 X 标签页发打开消息；从完整设置页选择当前窗口最近使用的 X 标签页。若不存在，则新建 `x.com/home`，通过一次性待打开状态等待内容脚本就绪；已有标签页不刷新。无法识别账号时显示提示，不能将多个账号数据混合显示。

## 4. 回看面板

桌面宽度 440px，固定于窗口右侧，100dvh 高；≤600px 时全屏。桌面不加遮罩，不重排主时间线；保持背景可滚动。滚动面板时 `overscroll-behavior: contain`，不连带滚动首页。已有的自定义时间线宽度不因面板改变。

| 区域 | 内容与规则 |
| --- | --- |
| 标题 | 左：历史图标、回看；右：设置、关闭，36px 点击区域 |
| 身份与状态 | 当前账号、已保存条数、记录中／记录已暂停；不得仅用颜色说明状态 |
| 搜索 | 40px 胶囊输入框；占位「搜索正文、作者或图片文字」；尾部清除输入 |
| 类型 | 全部／图片／视频／引用／转帖，单选，横向可滚动；继承现有轻量选中态 |
| 搜索辅助 | 结果数；OCR 关闭时显示「图片文字未开启」文字入口；识别中显示剩余图片数 |
| 分组 | 今天 14:20–14:28 · 首次看到；超过 10 分钟另起一组；旧日期按当前语言格式化 |
| 结果 | 32px 头像，作者与账号；正文优先，时间为弱化信息；媒体宽度跟随内容，最大高度 160px；引用块用细边框 |
| 项目操作 | 明确「打开原帖 ↗」链接；不整卡绑定点击，保留文字选择；可展开长文，不增加点赞／转发等操作 |
| 页脚 | 已显示／结果总数、加载更多；「最多保留 3000 条」说明在设置页，不占用每条记录空间 |

搜索输入防抖 150ms（设计目标），中文输入法 composition 期间不提前提交。匹配片段使用 DOM 文本与 `<mark>` 分段构建，禁止把推文 HTML 写入界面。默认按首次看到时间降序，发布于昨天但今天首次看到的帖子归今天。

当读者正在向下翻阅时，新记录只更新「有新记录」按钮，不自动插入导致位置跳动。点击后回到顶部。关闭再打开保留当次页面的关键词、筛选与滚动位置，换账号清空临时状态。新标签页打开原帖不会更新该记录的首次看到时间。

页面配色复用 `getThemeColors()`、`ACCENT`、`ACCENT_TEXT`、`getXFontFamily()`。支持 X 的白色、暗蓝、黑色以及用户自选强调色。不将设置页的铜橙色强制用于 X 页面。面板边框、阴影遵循现有收藏面板；桌面出现／关闭约 160ms，减少动态效果时取消位移动画。

键盘规则：打开后聚焦搜索；Esc 关闭；关闭后焦点返回入口。桌面是非模态 dialog，不锁定背景焦点；窄屏改为模态，使用焦点约束和 inert 背景。图标按钮有可访问名称，搜索结果数量使用低优先级 live region。触屏控件点击范围至少 44px。

## 5. 状态与文案

| 状态 | 表现／下一步 |
| --- | --- |
| 从未开启 | 「尚未开启自动记录」「开启后，会保存你在首页看到的推文。」主操作「开启自动记录」 |
| 已开启，无记录 | 「还没有回看记录」「在首页浏览推文后，会在这里显示。」操作「前往首页」仅在非首页显示 |
| 暂停，有记录 | 顶部「记录已暂停」；搜索、查看、清空继续可用；设置可恢复 |
| 过滤无结果 | 「没有找到匹配的推文」；保留搜索词和类型，提供「清除筛选」 |
| 读取中 | 展示有限骨架，不先显示无记录；失败后给「重新读取」 |
| 图片失效 | 显示「图片暂时无法加载」，正文和原帖链接保留；不承诺离线媒体备份 |
| 原帖失效 | 本地记录仍可见；只有实际请求验证后才显示失效，不根据缩略图失败推断推文已删 |
| 账号未识别 | 「暂时无法识别当前账号」；可重试；暂不采集，不默认打开上一个账号的记录 |
| 存储失败 | 「记录未保存，请重试」；不得把未成功提交条数计入已保存；读取旧记录仍可用 |
| 容量达到上限 | 自动淘汰最早首次看到记录，设置页说明；不弹提醒打断浏览 |
| 清空确认 | 「清空当前账号的回看记录？」说明将删除 {count} 条记录及图片文字索引，无法撤销；取消／确认清空 |

清空是事务操作，先增加账号数据代次并取消旧批次／OCR 任务，再删除数据；晚到的结果必须丢弃。清空后保留自动记录开关，当前已呈现的推文不立即重新写入，只有之后的新可见事件才记录。其他账号、本人帖子库、过滤日志和通用 OCR 语言数据不受影响。

## 6. 图片文字识别

默认关闭，首次打开说明：「在本机识别图片中的文字。首次使用需要下载识别数据，可能需要几分钟。」不能写成完全离线：识别计算在本机，但语言数据与图片来源需要网络，且来源服务器能看到请求。

- 开启准备：显示所需语言与待下载数据；中文界面默认简体中文＋英语；繁体及其他语言按插件 locale／实际浏览器地区判定。后续可扩充语言设置，不在主面板增加语言下拉。
- 下载：显示真实进度；若响应不含总大小，使用不确定进度，不编造百分比。
- 识别：显示「正在识别 · 剩余 {count} 张」，优先最新记录，一次处理一张。
- 可搜索：查询包含已完成结果；OCR 未完成不能宣称没有相关图片。
- 失败：说明「图片文字识别暂不可用」，保留正文搜索，提供重试／关闭。
- 关闭：停止新任务、释放 worker；已生成索引留在本机，但查询不再使用；清空记录时同步删除相关索引。
- 图片文本命中：卡片显示「图片文字匹配：…」，与推文正文区分，不把识别文本当作作者原文。

实现需要新增 offscreen 入口、`offscreen` 权限和 `wasm-unsafe-eval` CSP；引擎与 worker 随扩展打包。语言数据走固定版本路径，URL 限定为可信数据路径，禁止下载远程可执行脚本。图片仅允许已验证的 X 媒体 HTTPS 域名，使用 `credentials: omit`；不扩大为任意 URL 获取。现有 `optional_host_permissions` 可按需申请 OCR 数据／图片源权限，授权请求保持在用户点击的同步调用链。CORS、权限及离线缓存行为需要实装验证，当前未实测。

## 7. 技术接入方案

采用上游的可见采集、字段提取、搜索归一化和本地 OCR 思路；重写设置、入口与面板，接入 oh-my-x 的生命周期，不直接拼接上游 IIFE、全局 MutationObserver 或 storage 全量数组。

| 现有位置 | 计划变更 |
| --- | --- |
| `storage-keys.ts`、`shared/settings.ts` | 记录开关、入口显隐、OCR 开关与归一化；开关继续用 `on/off` |
| `shared/feature-registry.ts` | `rewind` 归属 `layout`；每个新 key 有唯一归属 |
| `shared/i18n/{zh-CN,en}.ts` | 新文案按现有 ID 规范加入中英表；设计评审稿只展示中文 |
| `entrypoints/popup/components/modules/LayoutModule.vue` | 阅读组加入 RewindCard；复用 FeatureCard、SubRow、SubPage |
| `entrypoints/options/OptionsApp.vue` | 保持共享模块；新增详细页定位状态，避免现有仅识别模块 hash 的解析器丢弃路径 |
| 新 `content-scripts/features/rewind.ts` | 可见监听、增量扫描、路由和账号变化处理；挂入现有 tweet/navigation scopes |
| 新 `content-scripts/options/rewind-panel.ts` | 页面面板、搜索、筛选、键盘行为和动态主题 |
| 新 `shared/rewind.ts` | 数据类型、采集阈值、去重合并、检索归一化、分组纯逻辑 |
| 新 `shared/rewind-db.ts` | 扩展源 IndexedDB repository，与本人帖子库分开 |
| `entrypoints/background.ts` | 校验来源的增量写入／查询／清空 RPC；串行化写入与账号代次 |
| 新 `entrypoints/rewind-ocr/*` | offscreen 识别页及 worker 生命周期 |
| `wxt.config.ts` | 专用 command、offscreen 与 OCR 配置；保持原 popup |

建议数据库 `oh-my-x-rewind`：`posts` 以 `[accountId, tweetId]` 为键，以 `[accountId, firstSeenAt]` 为时间索引；OCR 以 `[accountId, normalizedMediaUrl, languageVersion]` 为键。每条记录存正文、作者快照、媒体类型与 URL、引用、转帖上下文、发布时间与首次看到时间。不下载媒体副本；显式保存媒体类型，避免仅靠 URL 中含 `video_thumb` 分类。

存储只在扩展 origin 由后台操作，content script 发批量增量（目标每批 ≤20 条或 800ms）；3000 条按账号限制，同时对字段长度、OCR 文本、总占用做边界控制。初期按账号检索有限记录，不把全部内容写入 storage.onChanged。查询响应带请求序号，丢弃过期结果。

账号标识优先稳定 user ID；现有账号识别逻辑可复用，但无法确认时暂停采集。总开关关闭、离开首页、账号切换、内容脚本失效时取消观察和待写批次。采集前排除广告和被 oh-my-x 过滤的元素，延迟补齐媒体时重新验证账号、路由、可见性与数据代次。上游 1500ms 的补齐延时可保留为候选值，不直接把「曾可见」等同于「此刻可记录」。

## 8. 实施顺序与验收

1. 基础记录与数据库：可见阈值、账号隔离、原帖快照、容量淘汰、多标签页与清空事务。
2. 原生入口与阅读面板：设置卡片、导航、专用快捷键、搜索筛选、新标签阅读、三种 X 主题与窄屏。
3. 本地 OCR：下载进度、恢复、失败重试、停止、索引清理和语言数据缓存；本项是完整范围的一部分，不能将无 OCR 版本称为全部集成完成。
4. 同步中英文 README、隐私声明与第三方许可；进行浏览器验收后再发布。

以下是验收目标，尚非实测结果：

- 标准推文可见 49% 不记录、50% 记录；长推文使用视口 40% 规则，在两侧边界验证；隐藏标签页不记录。
- 首页推荐／关注记录；详情、搜索、个人页、广告及过滤折叠内容均不记录；排除翻译插件重复译文。
- 同帖重复出现不新增、不改变首次看到时间；晚加载字段可补齐；两个标签页同时写入不覆盖。
- 3001 条淘汰最早一条；账号切换不串数据；清空后迟到任务不能恢复旧记录。
