### 扩展错误页问题排查

用户截图包含两类独立消息：`Extension context invalidated` 和 OCR 的 `Parameter not found`。不能把打包文件第 68 行中同时包含的通知卡片、采集和面板代码视为同一个错误来源。

- 上下文失效：扩展重载后旧 X 页面的脚本仍可能运行。回看原先只在 `pagehide` 清理定时器，且关闭面板时直接调用 `storage.onChanged.removeListener`，失效上下文中的同步异常会外溢。现增加上下文有效性检查，停止定时器、DOM 监听和待采集任务，移除旧回看界面；清理扩展监听时允许上下文已经失效。筛选存储也改用项目已有的异步安全封装。单元回归覆盖重载后停止任务、清理同步异常与筛选写入同步异常。
- OCR 参数警告：对同一份 `chi_sim/4.0.0_best_int` 数据，实际运行精简 SIMD LSTM 内核，初始化成功但产生 8 条警告，与截图参数一致；完整 SIMD 内核初始化也成功，警告为 0。这是数据自带旧式参数与精简内核的兼容性问题，不是识别失败。改用完整内核，识别模式仍为 `OEM.LSTM_ONLY`，保留原缓存。WASM 从 2,857,601 字节变为 3,451,410 字节，构建总大小从约 4.79 MB 变为 5.38 MB。

上游中文/日文数据配置保留旧式参数的情况可参见 [Tesseract 官方语言配置](https://github.com/tesseract-ocr/langdata/blob/main/jpn/jpn.config)。现有 Chrome 错误记录不会因文件构建而改变；尚未刷新的 X 标签仍运行之前的内容脚本，新清理逻辑仅对加载了新构建的页面生效。

最终生产构建的隔离集成测试通过中文图片文字搜索、失效图片跳过、视频封面和链接缩略图识别、缓存复用、清空代次及账号边界。新增的实际扩展重载场景保留旧 X 文档与已打开的回看面板，调用隔离扩展的 `runtime.reload()` 后观察到旧导航及面板移除；再触发滚动、缩放和 Esc，未捕获 `Extension context invalidated`。此检查未操作用户 Chrome 的扩展设置或真实登录数据。

用户重载并刷新 X 后，最终真实页面复验通过：更多菜单自动收起、回看正常打开，保存记录为 11 条；OCR 从「正在识别 · 剩余 1 张」变为「图片文字已就绪」，搜索 `toughest` 命中 1 条图片文字结果。Esc 关闭与导航重新打开正常；当前 X 测试页可读取的警告／错误日志中，两次查询均未捕获 `Extension context invalidated`。不能将这个结果扩展为 Chrome 全局错误记录已清除或所有旧标签均无错误：扩展管理页和离屏文档日志仍受自动化策略限制，未直接读取。

真实页面截图只保存在本机临时文件 `/tmp/ohmyx-rewind-verified.png`，未放入仓库的示例截图目录。未提交或推送代码。

## 实现范围

- 首页可见推文采集、首次看到时间、补齐晚加载内容、去重、广告与过滤内容排除。离开首页或暂停记录后停止采集。
- 按账号隔离的扩展源 IndexedDB；每账号最多 3000 条、约 20 MB；清空以事务和代次校验阻止旧采集批次及迟到 OCR 恢复记录。
- 导航入口、更多菜单入口、设置页入口及 Alt+Shift+R；440px 右侧面板，600px 及以下全屏，支持搜索、类型筛选、分组、分页、正文展开与原帖新标签打开。
- 自动记录与图片文字识别默认关闭。暂停后可查阅；导航显隐独立保存。设置页可清空当前账号记录。
- 本地 Tesseract OCR、语言数据下载进度、缓存、任务恢复与重试；关闭后终止任务并停止使用图片文字搜索。引擎和 worker 随包，网络只用于获取语言数据和 X 图片。
- 中英文文案、README、隐私声明、MIT 与 Apache 许可文件。

数据库采用账号索引，在最多 3000 条的范围内排序和搜索；OCR 文本与语言标识直接保存在对应媒体记录中。设计中独立的 OCR 表与复合时间索引属于建议，未作为额外存储层加入。这样清空与容量淘汰能在同一事务中处理记录及其索引。

## 浏览器验证边界

测试加载真实生产扩展，使用虚构 X DOM、虚构账号 Cookie 和生成的测试图片；没有读取或修改用户登录数据。文字识别使用真实打包引擎，并从固定 CDN 获取实际语言数据。由于普通页面路由不能拦截离屏文档，图片通过 CDP 定向提供测试响应。

测试副本预先授予图片与语言数据两个来源权限，生产构建仍保持点击开启 OCR 时按需申请。初版隔离测试没有验证浏览器原生权限弹窗、真实登录 X 的当前 DOM、真实「更多」菜单挂载、浏览器快捷键冲突或繁体中文识别。后续真实页面覆盖范围见上方补充，不能把隔离验证视为所有 X 页面和浏览器版本的覆盖。

## 复现与截图

先执行 `npm run check`，再运行 `node scripts/test-rewind-extension.mjs`。脚本需要可用的 Playwright Core 和支持 MV3 扩展的 Chromium；可使用以下环境变量：

- `REWIND_PLAYWRIGHT_MODULE`：Playwright Core 模块路径；未指定时导入 `playwright-core`。
- `REWIND_CHROMIUM`：Chromium 可执行文件路径。
- `REWIND_TEST_LANGUAGE=zh-CN`：验证简体中文与英语；默认验证英语。
- `REWIND_SCREENSHOT_DIR`：截图目录；未指定时不保存截图。

脚本只复制构建到临时目录，不修改生产 manifest；结束时删除临时浏览器数据。图片与语言数据获取需要网络，其中测试图片由脚本提供。

## 文档与现有代码的差异

以下差异沿用实际代码处理：

1. `AGENT.md` 目录树把共享组件列到 `entrypoints/options/`；实际位于 `entrypoints/popup/`，完整设置入口是 `OptionsApp.vue`。本次复用实际共享组件。

3. 上游 README 的「露出一半以上」不完整；其代码为可见高度 ≥ min(推文高度 50%, 视口高度 40%)。本次按实际阈值实现并验证边界。
