## 功能特性

### 🎨 视图定制

- **时间线宽度** — 拖动滑块自由调整内容区域宽度（600~800px），充分利用宽屏空间
- **发帖按钮** — 显示/隐藏页面浮动发帖按钮
- **右侧边栏** — 显示/隐藏右侧趋势与推荐侧边栏
- **文章目录** — 悬浮 Notion 风格推文与长文两级目录导航（支持大标题 H1、副标题 H2 及写作防抖联动）
- **排期全景** — 定时发帖相对时间换算、时间间隔阈值预警与排期全景分布看板
- **未互关标记** — 在关注列表页自动标记未互相关注的用户账号
- **导航栏按钮管理** — 探索、通知、聊天、Grok、Premium、历史、创作者工作室、文章、个人资料、更多等 10 个按钮显隐控制，支持导航文本从不/悬停/始终显示

### ⚡ 爆款雷达与数据分析

- **爆款雷达（Viral Radar）** — 实时按流速（浏览量 ÷ 发布时长）测算推文热度，分级打标（潜力 / 爆款），支持边框与背景高亮
- **数据比例徽章** — 浏览个人主页时自动计算并标注推文的曝光比与互动比（对比主页作者粉丝数），支持评级标准对照

### 🛡️ 评论垃圾过滤器

**8 条智能检测规则**，可逐条开关：

| 规则 | 检测内容 | 默认分 |
|------|---------|--------|
| 🏷️ 营销昵称 | 昵称含"点击主页/同城/约会/固炮"等词 | +40 |
| 📊 Emoji 占比 | 评论中 emoji 超过文本一半以上 | +20 |
| 📝 评论过短 | 正文 < 8 个字符 | +10 |
| 🤖 随机用户名 | 用户名像随机字母+数字组合（多维可疑度判定） | +10 |
| 🔑 营销词库 | 评论命中自定义关键词列表 | +20 |
| 😊 纯 Emoji | 去掉 emoji 后内容为空 | +40 |
| ✨ 装饰昵称 | 昵称含 2 个以上 emoji | +15 |
| 🔁 重复字符 | 同字符连续重复 4 次以上（如"哈哈哈哈"） | +20 |

**核心能力：**
- 🔧 **自定义营销词库** — 自由添加你想屏蔽的营销/垃圾关键词
- 🎯 **一键选词** — 在任何推文下方点击 **＋** 按钮，从昵称和评论内容中快速提取关键词添加
- ⚪ **白名单** — 按 `@handle` 设置永不过滤的作者
- ⚫ **黑名单** — 按 `@handle` 强制隐藏该作者的全部评论
- 📊 **快捷操作** — 推文下方盾牌按钮，一键将作者加入白/黑名单
- 🎚️ **隐藏阈值** — 得分 ≥ 阈值（默认 55）的评论被隐藏，可在 20~150 区间调节
- 🔍 **调试模式** — 在每条评论下方显示评分和命中规则，帮你微调阈值和词库
- 📋 **拦截日志** — 本地保存最近 200 条拦截记录，支持按分类统计每日数据
- 🏠 **概览面板** — 今日拦截总数 + 分类统计网格 + 最近拦截预览

### 🔗 发帖辅助

- **插入链接按钮** — 在发帖编辑器插入当前页面的 URL（自动捕获发帖前所在页面的地址）
- **媒体下载** — 在分享菜单中增加 Download image/video 选项

## 安装

### Chrome 网上商店

> 即将上线

### 开发者模式加载

```bash
# 1. 克隆仓库
git clone https://github.com/fxzer/x-focus.git
cd x-focus

# 2. 安装依赖
npm install

# 3. 生产构建
npm run build

# 4. Chrome 中加载
chrome://extensions → 开发者模式 → 加载已解压的扩展
→ 选择 x-focus/.output/chrome-mv3/
```

## Popup 界面

设置面板是一个 **400px 宽**的弹出窗口，包含 7 个标签页：

| 标签 | 功能 |
|------|------|
| 👁️ 视图 | 时间线宽度、发帖按钮、右侧边栏、未互关标记、文章目录、排期全景、导航按钮与标签 |
| 📊 概览 | 净化总开关、今日拦截统计、隐藏阈值、调试模式、账号活动度、数据比例徽章配置 |
| ⚡ 爆款 | 爆款雷达阈值配置、级别筛选与高亮样式定制 |
| 📏 规则 | 8 条检测规则逐条独立开关 |
| 📖 词库 | 自定义营销词库编辑 + 词数统计 |
| 📋 名单 | 白名单 / 黑名单列表管理 |
| 📝 日志 | 拦截记录查看、刷新、清空 |

### 技术栈

| 领域 | 选型 |
|------|------|
| 扩展框架 | WXT + Vite |
| UI | Vue 3 + reka-ui |
| 样式 | Tailwind CSS 4 |

### 项目结构

```
x-focus/
├── entrypoints/
│   ├── content.ts       # 注入 x.com 的内容脚本（isolated world）
│   ├── interceptor.content.ts # MAIN world 数据拦截器（排期接口拦截）
│   ├── background.ts    # Service Worker（版本化默认词库同步）
│   └── popup/           # 设置面板（Vue 3 SPA）
├── content-scripts/     # DOM 操作和功能实现
│   ├── features/        # Static + Dynamic + Viral Radar + TOC 功能
│   ├── spam/            # 垃圾评论扫描引擎与规则检测
│   ├── options/         # 各功能选项（时间线、导航、编辑器、数据比例等）
│   └── utilities/       # 工具函数与 Storage 封装
├── shared/              # 跨环境共享逻辑（规则引擎、静态图标、数据类型）
├── test/                # Vitest 测试套件（单元、集成与样本测试）
└── storage-keys.ts      # 全部 storage key + 默认值
```

## 隐私

- **完全本地运行** — 所有设置、关键词列表、拦截日志均保存在浏览器本地（`browser.storage.local`），不上传任何外部服务器
- **最小化权限** — 仅申请 `storage` 权限用于本地保存用户设置，零多余权限
- **严格限定运行范围** — 仅在 `twitter.com`、`x.com` 和 `pro.x.com` 域名上匹配运行
