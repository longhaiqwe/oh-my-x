## 功能特性

### 🎨 视图定制

- **时间线宽度** — 拖动滑块自由调整内容区域宽度（600~800px），充分利用宽屏空间
- **发帖按钮** — 显示/隐藏页面浮动发帖按钮
- **右侧边栏** — 显示/隐藏右侧趋势与推荐侧边栏
- **长文目录** — 悬浮 Notion 风格推文与长文两级目录导航（支持大标题 H1、副标题 H2 及写作防抖联动）
- **排期全景** — 定时发帖相对时间换算、时间间隔阈值预警与排期全景分布看板
- **未互关标记** — 在关注列表页自动标记未互相关注的用户账号
- **用户粉丝数徽章** — 在关注/粉丝列表卡片及信息流推文头部自动标注博主粉丝数量（如「12.5万 粉丝」），Hover 悬停查看精确粉丝与关注数，支持全部/仅列表/隐藏自由切换
- **导航栏按钮管理** — 探索、通知、聊天、Grok、Premium、历史、创作者工作室、文章、个人资料、更多、X Money 等 11 个按钮显隐控制，支持导航文本从不/悬停/始终显示

### ⚡ 爆款雷达与数据分析

- **爆款雷达（Viral Radar）** — 实时按流速（浏览量 ÷ 发布时长）测算推文热度，分级打标（潜力 / 爆款），支持边框与背景高亮
- **数据比例徽章** — 浏览个人主页时自动计算并标注推文的曝光比与互动比（对比主页作者粉丝数），支持评级标准对照

### 🛡️ 评论垃圾过滤器

**8 条智能检测规则**，可逐条开关：

| 规则 | 检测内容 | 默认分 |
|------|---------|--------|
| 🏷️ 营销昵称 | 昵称含"点击主页/同城/约会/固炮"等词 | +40 |
| 📊 Emoji 占比 | 评论中 emoji 超过文本一半以上 | +20 |
| 📝 评论过短 | 正文 < 8 个字符 | +10 |
| 🤖 随机用户名 | 用户名像随机字母+数字组合（多维可疑度判定） | +10 |
| 🔑 垃圾词库 | 回复命中词库中的词（多词累加，最高 65） | +35 |
| 😊 纯 Emoji | 去掉 emoji 后内容为空 | +40 |
| ✨ 装饰昵称 | 昵称含 2 个以上 emoji | +15 |
| 🔁 重复字符 | 同字符连续重复 4 次以上（如"哈哈哈哈"） | +20 |

**核心能力：**
- 🔧 **垃圾词库** — 添加要识别的营销和垃圾关键词，与正文屏蔽词分开管理
- 🎯 **一键选词** — 在任何推文下方点击 **＋** 按钮，从昵称和评论内容中快速提取关键词添加
- ⚪ **白名单** — 按 `@handle` 设置永不过滤的作者
- ⚫ **黑名单** — 按 `@handle` 强制隐藏该作者的全部评论
- 📊 **快捷操作** — 推文下方盾牌按钮，一键将作者加入白/黑名单
- 🎚️ **隐藏阈值** — 得分 ≥ 阈值（默认 55）的评论被隐藏，可在 20~150 区间调节
- 🔍 **调试模式** — 在每条评论下方显示评分和命中规则，帮你微调阈值和词库
- 📋 **拦截日志** — 本地保存最近 50 条拦截记录，支持按分类统计每日数据
- 🏠 **今日拦截** — 「过滤」页显示今日拦截总数、分类统计和最近拦截

### 📋 X Lists

- **资料卡一键加列表 (HoverCard Quick Add)** — 鼠标悬停在用户头像或用户名上时，资料卡片内直接出现「+ List」按钮，点击弹出列表菜单一键加入，告别繁琐的原生多级操作
- **导航栏快捷入口** — 在左侧导航栏顶部常驻「我的 Lists」入口，点击快速展开全部列表分组并一键直达，免受官方二级菜单折叠困扰
- **Lists 快速同步与管理** — 在插件设置中一键同步当前登录账号已有的 Lists，或通过链接/ID 手动添加与管理

### 🔗 发帖辅助

- **引用我的帖子** — 发帖弹窗、首页与详情页回复框均可使用。按账号 ID 将帖子正文、文章标题、日期和链接存入扩展本地 IndexedDB；输入关键词即搜索全部已缓存内容，结果以左侧封面、右侧标题和摘要展示，文章优先使用封面并按原比例完整显示、普通帖子使用首张媒体缩略图，无图或加载失败时不显示图片区域，文字占满整行；点击结果插入当前草稿。旧缓存会在后续同步时逐步补齐封面地址。默认在打开已登录的 X 后自动分批同步历史记录，每页保存断点；可在设置 → 创作 → 引用我的帖子中关闭“自动同步我的帖子”，关闭后保留缓存，仍可搜索和手动同步；多标签页共享同步锁，可暂停和继续。X 保持登录且有页面打开时约每 30 分钟检查新帖，未完成历史同步每批最多 20 页、间隔 2.5 秒，后续批次自动继续；关闭页面后下次打开恢复。界面显示缓存数量、最近更新时间和未完成范围。受 X 返回范围限制，不能保证获取全部历史；本地副本可能保留已删除或更新前的内容，文章索引包含接口提供的标题与摘要。不会自动发帖。

- **AI 总结转发** — 使用自定义 OpenAI 兼容服务生成两个转发文案选项，由你选择填入草稿。首次使用或更换服务地址，在「创作 → AI 总结转发」填写配置并点击「授权并测试连接」；只申请该服务主机的访问权限，拒绝授权则不发送请求。生成时会发送原文、作者信息、文章标题及补充要求，API Key 用于服务认证；连接测试仅发送测试文本。每次请求 25 秒超时，点击取消或关闭面板会中止请求并丢弃迟到结果。服务商可能已经处理请求，取消不保证免除费用。远程服务建议使用 HTTPS。

- **媒体下载** — 在分享菜单中增加 Download image/video 选项


## Popup 界面

设置面板是一个 **400px 宽**的弹出窗口，按 5 个模块分标签（模块归属定义在 `shared/feature-registry.ts`）：

| 标签 | 模块 | 功能 |
|------|------|------|
| 界面 | 界面与阅读 | 时间线宽度、右侧边栏、发帖按钮、导航栏按钮与文字、长文目录 |
| 过滤 | 内容过滤 | 垃圾回复过滤（今日拦截、隐藏阈值、调试模式、9 条检测规则、垃圾词库）、正文关键词过滤与屏蔽词、账号例外（白名单 / 黑名单）、拦截记录 |
| 数据 | 数据洞察 | 看板：原创内容奖励计划、博主活动度；页面标注：爆款雷达、数据比例徽章、用户粉丝数 |
| 创作 | 创作与发布 | 引用我的帖子、AI 总结转发、排期全景 |
| 互动 | 互动与列表 | 快捷键与底部悬浮条、直达回复区、回复自动点赞、未互关标记、X Lists |

## 开发

```bash
npm install
npm run dev        # 开发模式（HMR）
npm run build      # 生产构建
npm test           # 运行单元、DOM 与集成测试
npm run typecheck  # 检查 TypeScript 与 Vue 脚本、模板
npm run check      # 类型检查 + 全量测试 + 生产构建
npm run zip        # 构建 + 打包 ZIP
npm run clean      # 清理构建产物
```

GitHub Actions 会在 push、pull request 和手动触发时执行 `npm ci` 与 `npm run check`，通过后保存 Chrome 扩展构建产物 7 天。CI 使用 Node.js 24；本地建议使用 Node.js 24.15 或更新的 24.x。

### 项目结构

```
oh-my-x/
├── entrypoints/
│   ├── content.ts       # 注入 x.com 的内容脚本（isolated world）
│   ├── interceptor.content.ts # MAIN world 数据拦截器（排期接口拦截）
│   ├── background.ts    # Service Worker（版本化默认词库同步）
│   └── popup/           # 设置面板（Vue 3 SPA）
├── content-scripts/     # DOM 操作和功能实现
│   ├── features/        # Static + Dynamic + Viral Radar + TOC 功能
│   ├── spam/            # 垃圾评论扫描引擎与规则检测
│   ├── options/         # 各功能选项（时间线、导航、编辑器、数据比例等）
│   └── utilities/       # 工具函数与 Storage 封装
├── shared/              # 跨环境共享逻辑（规则引擎、静态图标、数据类型）
├── test/                # Vitest 测试套件（单元、集成与样本测试）
└── storage-keys.ts      # 全部 storage key + 默认值
```

## 隐私

- **本地保存** — 设置、关键词、拦截日志及 AI API Key 保存在 `browser.storage.local`，帖子库保存在扩展本地 IndexedDB。API Key 未由扩展加密，界面遮罩仅用于隐藏显示。
- **X 请求** — 帖子同步、Lists、用户指标、创作者奖励和互动辅助会使用已有登录会话与 X 通信。开发者不接收这些数据，也不收集遥测。
- **可选 AI 请求** — 只有用户主动生成或测试时，才向已授权的服务地址发送相应内容；该服务商的数据和计费条款适用。AI 请求不携带浏览器 Cookie。
- **权限** — 使用 `storage`、`cookies`、`alarms`、`downloads`；默认主机权限限于 X 相关域名和 `abs.twimg.com`。自定义 AI 主机通过可选权限按需授权，可在 Chrome 扩展设置中管理。
- **脚本运行范围** — 仅在 `twitter.com`、`mobile.twitter.com`、`x.com`、`pro.x.com` 注入页面脚本。

详见 [隐私政策](PRIVACY.md)。
