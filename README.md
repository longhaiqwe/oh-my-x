## 功能特性

按设置弹窗的 5 个模块排列，名称与弹窗一致。

### 🎨 界面与阅读

- **时间线宽度** — 在 600 到 800 像素之间调整主时间线的宽度
- **隐藏右侧边栏** — 隐藏右侧的搜索、推荐关注和趋势栏
- **隐藏发帖按钮** — 隐藏左侧导航栏里的发帖按钮，隐藏后可以按 N 发帖
- **导航栏按钮** — 探索、通知、聊天、Grok、Premium、历史、文章、个人资料、更多、X Money 共 10 个按钮可以分别隐藏；被 X 收进「更多」菜单的入口，也会在菜单里一起隐藏。导航文字可设为从不、悬停或始终显示
- **长文目录** — 在长文页和长文编辑器侧边，按一级和二级标题生成目录，点击跳到对应位置
- **媒体下载** — 在推文的分享菜单里加入下载图片、GIF 和视频（MP4）的选项，样式与菜单里的其他项一致。你自己发的视频，X 菜单里已有「下载视频」，这时不再重复加入

### 🛡️ 内容过滤

- **垃圾回复过滤** — 按规则给回复打分，得分达到隐藏阈值（默认 55，可在 20 到 150 之间调整）的回复会被隐藏。只给推文详情页对话里的回复打分，首页等时间线不处理

**9 条检测规则**，可逐条开关：

| 规则 | 检测内容 | 默认分 |
|------|---------|--------|
| 🏷️ 营销昵称 | 昵称含"点击主页/同城/约会/固炮"等词 | +40 |
| 📊 Emoji 占比 | 评论中 emoji 超过文本一半以上 | +20 |
| 📝 评论过短 | 正文 < 8 个字符 | +10 |
| 🤖 随机用户名 | 用户名像随机字母+数字组合（多维可疑度判定） | +10 |
| 🔑 垃圾词库 | 回复命中词库中的词（多词累加，最高 65） | +35 |
| 😊 纯 Emoji 评论 | 去掉 emoji 后内容为空 | +40 |
| ✨ 装饰昵称 | 昵称含 2 个以上 emoji | +15 |
| 🔁 重复字符 | 同字符连续重复 4 次以上（如"哈哈哈哈"） | +20 |
| 🔗 矩阵引流 | 回复中 @ 其他账号，并带随机字符或表情 | +20 |

- **垃圾词库** — 回复命中词库中的词时加分：第一个词 +35，每多命中 1 个不同的词再加 15，最高 65。和正文屏蔽词分开管理
- **一键选词** — 推文右上角「更多」按钮旁的选词按钮，从昵称和回复内容里选词加入词库
- **账号例外** — 按 `@handle` 设置白名单和黑名单：白名单作者的回复不隐藏，黑名单作者的回复全部隐藏。推文右上角「更多」按钮旁的名单按钮可以直接加入
- **调试模式** — 在每条回复下显示得分和命中的规则，用来调整阈值和词库
- **拦截记录** — 本机保存最近 50 条被隐藏的回复，按分类统计每天的数量；「过滤」页显示今日拦截总数和最近拦截
- **正文关键词过滤** — 信息流中正文含屏蔽词的推文会被折叠或隐藏

### ⚡ 数据洞察

- **原创内容奖励计划** — 在弹窗里显示创作者奖励计划的曝光进度和准入条件
- **博主活动度** — 在博主主页统计近 7 天的帖子数和回复数
- **爆款雷达** — 按每小时浏览量（浏览量 ÷ 发布时长）把推文分为普通、潜力和爆款，在信息流中加标签，可选边框或背景高亮
- **数据比例徽章** — 在博主主页的推文下显示浏览量、互动量与作者粉丝数的比值，可对照评级标准
- **用户粉丝数** — 在推文作者旁和关注、粉丝、搜索等用户列表中显示粉丝数（如「12.5万 粉丝」），悬停查看精确的粉丝数和关注数；可选全部、仅列表或关闭
- **收藏量** — 在推文的书签按钮旁显示收藏数，可在「数据 → 页面标注」关闭；关闭后已显示的数字会立即移除

### 🔗 创作与发布

- **引用我的帖子** — 发帖弹窗、首页与详情页回复框均可使用。按账号 ID 将帖子正文、文章标题、日期和链接存入扩展本地 IndexedDB；输入关键词即搜索全部已缓存内容，结果以左侧封面、右侧标题和摘要展示，文章优先使用封面并按原比例完整显示、普通帖子使用首张媒体缩略图，无图或加载失败时不显示图片区域，文字占满整行；点击结果插入当前草稿。旧缓存会在后续同步时逐步补齐封面地址。默认在打开已登录的 X 后自动分批同步历史记录，每页保存断点；可在设置 → 创作 → 引用我的帖子中关闭“打开 X 时自动同步”，关闭后保留缓存，仍可搜索和手动同步；多标签页共享同步锁，可暂停和继续。X 保持登录且有页面打开时约每 30 分钟检查新帖，未完成历史同步每批最多 20 页、间隔 2.5 秒，后续批次自动继续；关闭页面后下次打开恢复。界面显示缓存数量、最近更新时间和未完成范围。受 X 返回范围限制，不能保证获取全部历史；本地副本可能保留已删除或更新前的内容，文章索引包含接口提供的标题与摘要。不会自动发帖。

- **AI 总结转发** — 在发帖和引用编辑器里，点「每个人」右侧的按钮，使用自定义 OpenAI 兼容服务生成两个转发文案选项，由你选择填入草稿。首次使用或更换服务地址，在「创作 → AI 总结转发」填写配置并点击「授权并测试连接」；只申请该服务主机的访问权限，拒绝授权则不发送请求。可在「转发风格」里填写自己的风格描述和 2 到 5 条参考样本，留空时使用默认的平实风格。生成时会发送原文、作者信息、文章标题、转发风格及补充要求，API Key 用于服务认证；连接测试仅发送测试文本。每次请求 25 秒超时，点击取消或关闭面板会中止请求并丢弃迟到结果。服务商可能已经处理请求，取消不保证免除费用。远程服务建议使用 HTTPS。

- **排期全景** — 在定时发布弹窗和草稿箱里列出所有定时帖的发布时间和间隔，间隔过短时提示

### 📋 互动与列表

- **快捷键** — 在推文详情页按 1 到 4，分别回复、引用、点赞、收藏
- **底部悬浮条** — 在推文详情页底部显示这四个操作的按钮
- **直达回复区** — 长文和长推文页右下角的按钮，点击跳到评论区，再点一次回到正文；按住可以拖到别的位置，位置会记住
- **回复自动点赞** — 回复别人的推文后，给这条推文点赞；点赞前随机等待 0.3 到 0.7 秒，已赞过的推文和自己的推文不点
- **未互关标记** — 在你的「正在关注」列表里，把没有关注你的账号标红
- **X Lists**
  - 鼠标悬停在头像或用户名上时，资料卡里出现「+ List」按钮，点击后选择列表加入
  - 左侧导航栏加入「我的 Lists」入口，位置可选「Home 上方」或「列表区」，切换后立即生效；点击展开全部列表
  - 在设置里同步当前账号已有的 Lists，或通过链接、ID 手动添加

## Popup 界面

设置面板是一个 **400px 宽**的弹出窗口，按 5 个模块分标签（模块归属定义在 `shared/feature-registry.ts`）：

| 标签 | 模块 | 功能 |
|------|------|------|
| 界面 | 界面与阅读 | 时间线宽度、右侧边栏、发帖按钮、导航栏按钮与文字、长文目录、媒体下载 |
| 过滤 | 内容过滤 | 垃圾回复过滤（今日拦截、隐藏阈值、调试模式、9 条检测规则、垃圾词库）、正文关键词过滤与屏蔽词、账号例外（白名单 / 黑名单）、拦截记录 |
| 数据 | 数据洞察 | 看板：原创内容奖励计划、博主活动度；页面标注：爆款雷达、数据比例徽章、用户粉丝数、收藏量 |
| 创作 | 创作与发布 | 引用我的帖子、AI 总结转发、排期全景 |
| 互动 | 互动与列表 | 快捷键与底部悬浮条、直达回复区、回复自动点赞、未互关标记、X Lists |

「过滤」页分两层：第一层显示每个功能的开关和当前状态，点卡片右下角的「详细设置」「管理屏蔽词」「管理名单」「全部记录」进入第二层，左上角返回。

**完整设置页**：点弹窗右上角的「完整设置」按钮，会在新标签页整页打开设置，并定位到弹窗当前所在的模块；也可以在 `chrome://extensions` 的扩展详情里点「扩展程序选项」打开。设置页和弹窗内容相同、设置共用，适合编辑词库、名单和 AI 服务配置。地址末尾的 `#layout`、`#filter`、`#insight`、`#create`、`#engage` 对应五个模块。

## 开发

```bash
npm install
npm run dev        # 开发模式（HMR）
npm run build      # 生产构建
npm test           # 运行单元、DOM 与集成测试
npm run typecheck  # 检查 TypeScript 与 Vue 脚本、模板
npm run check      # 类型检查 + 全量测试 + 生产构建
npm run zip        # 构建 + 打包 ZIP
npm run clean      # 清理构建产物
```

GitHub Actions 会在 push、pull request 和手动触发时执行 `npm ci` 与 `npm run check`，通过后保存 Chrome 扩展构建产物 7 天。CI 使用 Node.js 24；本地建议使用 Node.js 24.15 或更新的 24.x。

### 项目结构

```
oh-my-x/
├── entrypoints/
│   ├── content.ts       # 注入 x.com 的内容脚本（isolated world）
│   ├── interceptor.content.ts # MAIN world 数据拦截器（排期接口拦截）
│   ├── background.ts    # Service Worker（默认词库同步、帖子库、Lists 与媒体请求、创作者奖励、AI 请求）
│   ├── popup/           # 设置弹窗（Vue 3 SPA，5 个模块标签）
│   └── options/         # 完整设置页（新标签页打开，复用弹窗的模块页）
├── content-scripts/     # DOM 操作和功能实现
│   ├── features/        # 页面功能（爆款雷达、长文目录、Lists、快捷互动、AI 转发等）
│   ├── spam/            # 垃圾评论扫描引擎与规则检测
│   ├── options/         # 各功能选项（时间线、导航、编辑器、数据比例等）
│   └── utilities/       # 工具函数与 Storage 封装
├── shared/              # 跨环境共享逻辑（功能清单、规则引擎、AI 提示词、数据类型）
├── test/                # Vitest 测试套件（单元、集成与样本测试）
└── storage-keys.ts      # 全部 storage key + 默认值
```

## 隐私

- **本地保存** — 设置、关键词、拦截日志及 AI API Key 保存在 `browser.storage.local`，帖子库保存在扩展本地 IndexedDB。API Key 未由扩展加密，界面遮罩仅用于隐藏显示。
- **X 请求** — 帖子同步、Lists、用户指标、创作者奖励和互动辅助会使用已有登录会话与 X 通信。开发者不接收这些数据，也不收集遥测。
- **可选 AI 请求** — 只有用户主动生成或测试时，才向已授权的服务地址发送相应内容；该服务商的数据和计费条款适用。AI 请求不携带浏览器 Cookie。
- **权限** — 使用 `storage`、`cookies`、`alarms`、`downloads`；默认主机权限限于 X 相关域名和 `abs.twimg.com`。自定义 AI 主机通过可选权限按需授权，可在 Chrome 扩展设置中管理。
- **脚本运行范围** — 仅在 `twitter.com`、`mobile.twitter.com`、`x.com`、`pro.x.com` 注入页面脚本。

详见 [隐私政策](PRIVACY.md)。
